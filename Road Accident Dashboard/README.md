# Road Accident Analytics Dashboard

This project is an interactive Excel dashboard built to analyze UK road accident data and identify key safety trends. Adapted from a community tutorial, I developed this workspace to practice data cleaning, metric aggregation, and visualization techniques using large-scale data.

**Project Highlights**
* **Data Scale:** Processed a raw CSV dataset (`DataSet_accident data.csv`) containing 660,679 individual accident records spanning from 2019 to 2022.
* **Casualty Metrics:** Aggregated data for over 896,000 total casualties, allowing users to drill down by accident severity.
* **Environmental Factors:** Built visualizations tracking how weather, light conditions, and road surfaces impact incident rates.
* **Geographical & Vehicle Segmentation:** Tracks accidents across rural versus urban areas and 16 distinct vehicle types.

**Dashboard Features**
The `ROAD ACCCIDENT DASHBOARD 2021-22.xlsx` file includes a dedicated **DASHBOARD** sheet powered by connected PivotTables. Key performance indicators update dynamically based on user-selected time periods or district areas via interactive slicers.
