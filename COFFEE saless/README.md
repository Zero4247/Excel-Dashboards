# HR Recruitment Analytics Dashboard (Excel)
Interactive Excel dashboard designed to analyze recruitment data, evaluate candidate performance, and support data-driven hiring decisions.
The dashboard explores candidate attributes and hiring outcomes through visualizations, candidate evaluation tools, and interactive filters.

# Key Features

1. Recruitment KPI overview (Total Candidates, Hires, Hiring Rate)
2. Hiring trend analysis by education, experience, and scores
3. Candidate Profile Analyzer with competency radar chart
4. Candidate Comparison Tool for side-by-side evaluation
5. Hiring Probability Calculator based on candidate scores
6. Interactive filters and dashboard navigation

# Dataset: 
1,500 candidate records with attributes such as education, experience, interview score, skill score, and hiring decision.

# Tools Used

1. Microsoft Excel
2. Pivot Tables & Charts
3. Excel Formulas
4. Slicers
5. VBA Macros
